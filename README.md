# Maxwell Ngangira — Executive Website

A static, responsive personal website designed for GitHub Pages.

## Publish on GitHub Pages

1. Upload all files and folders in this directory to the root of your GitHub repository.
2. In GitHub, open **Settings → Pages**.
3. Set **Source** to **Deploy from a branch**.
4. Select **main** and **/(root)**, then save.
5. Wait for the Pages deployment to complete.

The site requires no build step and no external framework.

## Important structure

Keep these at repository root:
- `index.html`
- `styles.css`
- `script.js`
- `assets/`

## Updating content

Edit `index.html` for text, `styles.css` for design, and replace files in `assets/images/` or `assets/files/` while preserving filenames.
