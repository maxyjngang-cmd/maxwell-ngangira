# Maxwell Ngangira — Executive Website

Static website prepared for GitHub Pages.

## Publish on GitHub Pages

1. Extract the ZIP.
2. Copy everything inside this folder into the root of your `maxwell-ngangira` repository.
3. Commit and push the changes to `main`.
4. In GitHub, open **Settings → Pages**.
5. Set **Source** to **Deploy from a branch**, branch **main**, folder **/(root)**.
6. Save and wait for the Pages deployment to finish.

The repository root must contain `index.html`, `styles.css`, `script.js`, and the `assets` folder.

## Image handling

All photographs retain their original aspect ratios. CSS uses `height: auto`; no image is stretched or forced into a fixed-height crop.
